# DOIT product documents

Supplementary DOIT module manuals, schematics and certificates curated by ESP32S.com. For manuals already published upstream, see the [DOIT specification repository](https://github.com/doit-open-org/chip_specification_sheet). For setup instructions, see the [ESP32S DOIT Wiki](https://esp32s.com/wiki/?wiki_search=DOIT).

Browse the [DOIT storefront](https://esp32s.com/product-category/doit/) or the [Modules catalog](https://esp32s.com/product-category/modules/) on ESP32S.com. Where a listed product is available, its purchase link is shown below.

Manufacturer documents retain their original notices. Confirm model, hardware revision and applicable certificate scope before relying on these files.

The P4 manual copy uses the same printed version/date as the upstream PDF but differs in its power table heading and packing details. Confirm the applicable revision with DOIT. The ESP-02S manual here is the Chinese edition.
